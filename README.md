\# Team Pura Website



\## About the Project

Team Pura Website is a WordPress-based website developed as a group project. It showcases the team's work, information, and web design skills through a customized website.



\## Technologies Used

\- WordPress

\- PHP

\- HTML

\- CSS

\- JavaScript

\- MySQL



\## Project Structure

\- `plugins/` - Contains the installed WordPress plugins.

\- `themes/` - Contains the website themes and customizations.



\## Features

\- Responsive website design

\- Customized WordPress theme

\- User-friendly interface

\- Organized website content



\## Developers

Team Pura



\## Project Purpose

This project was developed to apply web development skills and demonstrate the use of WordPress in creating and customizing a website.
